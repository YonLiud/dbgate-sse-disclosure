# DbGate Unauthenticated SSE Disclosure

Identifier: `GHSA-297r-vfh5-2xqc`

```
CVSS:3.1/AV:N/AC:L/PR:N/UI:N/S:U/C:L/I:N/A:N
```
Score: 5.3 (Medium).

Affected version: 7.3.0 built from commit `9cf8ddd5da1673c5774b847af8dca9dcb5fb1be6`

## Description
Exposed global Server-Sent Events stream at `/stream` without requiring authentication.

An unauthenticated requester can connect to the endpoint and receive events generated by other activity in the instance. The observed events disclosed:

- SQL statements
- Session and process identifiers
- Query timing and row counts
- Internal plugin and runtime metadata

The stream did not return query result rows in the tested case, but it still crossed the expected session boundary and disclosed SQL and execution metadata.
The optional `strmid` parameter was not required for reproduction and does not provide authorization or isolation.
